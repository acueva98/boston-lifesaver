# Cambridge, MA restaurant list

Seed list of 44 restaurants in Cambridge, MA for the Boston Lifesaver app.

- `cambridge_restaurants.json`: `{ city, last_updated, count, restaurants[] }`
- `cambridge_restaurants.csv`: same rows, flat

Fields: `id`, `name`, `neighborhood`, `cuisine`, `address`, `zip`, `price_range` ($–$$$$, approximate).

Last checked: 2026-10-05. Places reported closed in 2025–26 (e.g. Dear Annie, Tampopo, S&S Deli, Beyond Full, Turing Tavern) are excluded. Hours, prices and status change, so re-check before relying on any entry.
