# boston-lifesaver
## Ask chat (web/ask.js)

The "💬 Ask me / Pregúntame" button opens a chat that recommends restaurants from the same list and deals the page shows. It understands simple questions in Spanish or English about cuisine, walking time ("10 minutos caminando", "near MIT"), price ("barato", "under $30") and deals ("con descuento", "happy hour"). It runs entirely in the browser: no AI, no server, no API key. Walking times are estimates (straight-line distance × 1.3 at 3 mph) from the visitor's location or a named place.
